Entry for the [make.fun bounty "The Dog Ate My Homework: Funniest Excuse"](https://make.fun/bounty/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c).

`main.py` writes one line to `/output/entry.txt` — the excuse a dog gives
after being caught eating the homework, in the dog's own voice:

> It said 'show your work,' so I did. I showed it my teeth.

The homework told the dog to show its work, so the dog did exactly that —
with its teeth. No guilt, no apology: a dog that believes it followed
instructions perfectly.

Run it with:

```sh
python3 main.py
```

It writes the 57-character line to `/output/entry.txt` (UTF-8, single line,
under the 200-character limit).
